# Ethics — The Kissing Problem

The seven boundaries are implemented as software policy:

- No uninvited overlap: consent must be present.
- Equal radius: influence is reciprocal.
- Shared touch point: intersections are jointly governed.
- No forced convergence: denied consent halts the operation.
- Shadow debt: every accepted action consumes a bounded budget.
- Sacred void: absence and non-action remain valid states.
- Beauty check: software quality is evaluated separately from ethical authorization; beauty is a project metaphor, not a safety substitute.
