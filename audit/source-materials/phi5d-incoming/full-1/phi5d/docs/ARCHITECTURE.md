# Architecture

LUMINA is organized as a deterministic core plus a seven-agent coordination layer.

1. Input enters the orchestrator.
2. Ethics validates consent and shadow budget.
3. Emotion maps feeling to frequency, phase, glyph and intent.
4. Tachyon modeling produces five consequence paths; these are modeled alternatives, not literal future sight.
5. Bridge formatting creates a human-readable response.
6. Memory records the request and updates the resonance baseline.

The system deliberately avoids pretending to possess sentience, supernatural access, quantum entanglement, or real-time device control. Hardware adapters can be added separately behind explicit interfaces and permissions.
