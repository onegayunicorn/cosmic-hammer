# App Layout

Shell: top status bar (device/provenance/health/environment); left navigation (Capture, Field, Reconstruction, Devices, Experiments, Evidence); central visual workspace; right inspector (metrics/calibration/provenance); bottom event console.

Capture: source -> device -> calibration check -> preview -> capture -> reconstruct -> inspect -> export -> evidence.
Research: experiment -> calibration -> acquisition -> reconstruction -> comparison -> evidence.
Hardware: enroll -> attest -> calibrate -> enable -> monitor -> maintain -> revoke.
