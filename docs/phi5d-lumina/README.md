# Phi-5D / Lumina Integration

This integration turns the supplied Lumina archives and Sovereign Lattice specifications into a deterministic, software-only feature set for Cosmic Camera and Cosmic Hammer.

## Connected surfaces

The React app exposes a live simulated camera surface, a real-world narrative builder, a symbol-to-code translation matrix, a compass view, and an Obsidian Shard device page. The shard page models a J09-style Bluetooth relationship with `BLUETOOTH_SIMULATED` provenance; it does not scan, pair, write to, or control a physical Bluetooth device.

The TypeScript core provides the seven-agent vocabulary from the supplied Lumina reference, deterministic frequency and glyph translations, a derived compass, a simulated shard-device state, runtime safety checks, and a 104-episode plan of weekly 30-minute narrative simulations across two years.

## Commands

```bash
pnpm simulate:phi5d-lumina
pnpm test:unit
pnpm build
```

The smoke output is derived or simulated. It must not be interpreted as measured photon data, physical device presence, firmware verification, optical-bench qualification, or live Bluetooth/NFC/GPS connectivity.

## Source traceability

The supplied ZIP archives are preserved under `audit/source-materials/phi5d-incoming/`. They are treated as reference material. Placeholder firmware, APKs, FPGA images, hardware schematics, cloud endpoints, and claims of physical liveness are not executed or promoted to verified evidence.
